# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm ci`.
3. Make your change and add or update tests where appropriate.
4. Run `npm run typecheck`, `npm test`, and `npm run build`.
5. Open a pull request describing the change and how it was verified.

Keep changes small and avoid committing generated output, local environment files,
credentials, or unrelated dependencies.
